My custom 404 error page

I have a custom 404 error page for this website, which you will see when you go to any url under this domain that does not exist, e.g. zzalbert.com/present-king-of-France/. In addition to the normal 404 error message, the page contains a philosophy quote about "existence" or "non-existence," which is randomly selected each time the page is accessed.

Turns out these rodents also secretly run the university I go to, i.e. UofT (see this reddit post), which is pretty cool. (Just kidding, of course.
